# WinTile5 - 5 窗口分屏助手 (与 Windows 11 原生 2x2 模式零冲突)

<div align="center">

[English Documentation](README_EN.md) | [中文说明](README.md)

</div>

按 `Win + Alt + A` 一键把 **4 个 CLI 终端 + 1 个主界面** 排成：左侧 2×2 四个终端，右侧一个全高主界面。

- 左半区：4 个终端按 2×2 排布（槽位 7:左上, 8:右上, 1:左下, 2:右下）
- 右半区：1 个主界面（槽位 6:右侧全高）
- 全部窗口**严丝合缝**：无缝隙、无重叠、无圆角弧形缺口。

## 🧭 Win + Alt + 方向键 状态机流动规则

WinTile5 拥有唯一的几何数据源 `GetLayoutInfo()`，左半区 2×2 区域内复用原版逻辑，并支持复合半区分屏（78:上半宽, 12:下半宽, 71:左列全高, 82:右列全高, 7812:左半区全高）：

### 1. 向右键 (Right)
- `7` (左上) → `78` (上半宽) → `8` (右上) → **`6` (右侧全高)**
- `1` (左下) → `12` (下半宽) → `2` (右下) → **`6` (右侧全高)**
- `71` (左列全高) → `7812` (左半区全高) → `82` (右列全高) → **`6` (右侧全高)**
- `6` → 保持 `6`
> **核心铁律**：在已知状态下，**只有在 8、2 或 82（右列）位置再按一次右键才进入 6 号主位**；在左侧 7、1 区域内按右键严格在 2×2 网格内流动，绝不误入 6 号位！

### 2. 向左键 (Left)
- **`6` (右侧全高) → `82` (右列全高)** → `7812` (左半区全高) → `71` (左列全高) → 保持 `71`
- `8` (右上) → `78` (上半宽) → `7` (左上) → 保持 `7`
- `2` (右下) → `12` (下半宽) → `1` (左下) → 保持 `1`

### 3. 向上键 (Up)
- `1` (左下) → `71` (左列全高) → `7` (左上) → 保持 `7`
- `2` (右下) → `82` (右列全高) → `8` (右上) → 保持 `8`
- `12` (下半宽) → `7812` (左半区全高) → `78` (上半宽) → 保持 `78`
- `6` → 保持 `6`

### 4. 向下键 (Down)
- `7` (左上) → `71` (左列全高) → `1` (左下) → 保持 `1`
- `8` (右上) → `82` (右列全高) → `2` (右下) → 保持 `2`
- `78` (上半宽) → `7812` (左半区全高) → `12` (下半宽) → 保持 `12`
- `6` → 保持 `6`

### 5. 自由浮动窗口 (Unknown) 智能几何推导规则
当一个未分屏或由于终端最小尺寸限制超出容差的窗口按下方向键时，通过 `FindClosestLayoutState` 基于物理边界与中心点自适应推导出当前视觉最贴合的槽位，并在 10 状态转移表中平滑流转：
- 位于 7 号位区域按下键 → 精准进入 `71` (左列全高)，彻底杜绝跳跃至 12
- 位于 8 / 2 / 82 号位区域按右键 → 精准进入 `6` (右侧全高)
- 位于 6 号位主区域按左键 → 精准回到 `82` (右列全高)
- 位于 78 号复合区按下键 → 精准进入 `7812` (左半区全高)
- 位于 12 号复合区按上键 → 精准进入 `7812` (左半区全高)

## 🔧 四个核心底层关键细节

### 1. 隐形边框补偿（告别缝隙与重叠）
Windows 11 给每个普通窗口添加了 9px 隐形边框。WinTile5 通过 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` 实时获取可见边界，并计算内缩量 `iL, iT, iR, iB`，在 `WinMove` 时精准补偿，使各窗口之间**物理可见像素严丝合缝**。

### 2. 终端最小宽度保护
Windows Terminal 等终端存在硬性最小宽度（约 714px）。WinTile5 会在首次排版时自动实测最小宽度，保证左半区两列宽度不低于终端限制，彻底杜绝窗口因尺寸超限相互重叠。

### 3. 全直角无缝模式与精准退出恢复
去除接缝处的圆角弧形黑洞（`DWMWCP_DONOTROUND`）。脚本仅对实际处理过的窗口记录 HWND，脚本退出时（`OnExit`）仅恢复这些受影响窗口的默认圆角，不污染系统中的其它应用。

### 4. 冷启动首次排版二次精调保障 (Two-Pass Guarantee)
首次排版时，窗口可能处于最大化或系统原生贴靠状态，还原动画与 DWM 非客户区重绘存在微小异步时滞。WinTile5 在底层自动执行冷启动二次微调复位，确保用户初次使用无需按第二次快捷键即可 100% 严丝合缝。

## 📁 目录结构

```text
D:\WinTile5\
├── auto_layout.ahk          # 核心脚本 (唯一几何源 / 40项状态机 / DWM补偿)
├── setup_startup.bat        # 写入开机自启并启动 WinTile5
├── uninstall_startup.bat    # 移除开机自启
├── run_layout.bat           # 双击直接执行 5 窗口排版
├── README.md                # 完整技术与操作文档
└── bin\
    ├── AutoHotkey64.exe     # 绿色便携运行时 (免安装 / 零依赖)
    ├── startup_shortcut.ahk # 开机自启快捷方式创建与清理工具
    ├── arrange_now.ahk      # 一键排版触发小脚本
    ├── restart.bat          # 重启后台服务
    ├── verify.bat           # 自动化无弹窗语法与40项状态机断言测试
    ├── _verify.ahk          # 40 项状态机自动化测试脚本
    ├── WindowSpy.ahk        # AHK 官方窗口探测器
    └── AutoHotkey.chm       # AHK 文档
```

## 🚀 启动与开机自启

- **配置开机自启**：双击 `setup_startup.bat`
- **移除开机自启**：双击 `uninstall_startup.bat`
- **重启脚本**：双击 `bin\restart.bat`
- **执行测试**：双击 `bin\verify.bat`
- **目录迁移**：双击 `rename_to_WinTile5.bat`（自动从 `D:\new` 平滑迁移至 `D:\WinTile5`）
